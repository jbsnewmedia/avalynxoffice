## Release 1.0.0-rc1 – Changelog Summary

First release candidate of **AvalynxOffice**, the Symfony 8 based mail
system (POP3 retrieval, management, SMTP sending). Source-available
licensing: free for up to 3 active user accounts (community), commercial
license beyond.

* **Mail Core**
  POP3 retrieval workers, mailbox and folder management, full-text search
  and SMTP sending through pluggable connectors.
  Covers the daily mail workflow end to end in a self-hosted setup.
* **Calendar and Contacts**
  Calendar events with edit/delete action plugins and a shared contact
  address pool used by mail and device synchronization.
* **Licensing Enforcement**
  Central license state with a read-only mirror: device writes and outgoing
  mail honor the license policy (community, commercial, read-only).
  Keeps the community boundary technically enforceable.
* **ActiveSync via avalynxofficeeas**
  Exchange ActiveSync device synchronization ships as the separate AGPL-3.0
  project [`jbsnewmedia/avalynxofficeeas`](https://github.com/jbsnewmedia/avalynxofficeeas),
  sharing this database schema as the interface.
  No core code is embedded; deployment runs as its own container.
* **Production Docker Image**
  PHP 8.5 image published to Docker Hub as `jbsnewmedia/avalynxoffice`
  (`latest` on the default branch, semver tags for releases).
  Includes the compose-ready deployment layout and update script.
* **Quality Gates**
  PHPUnit suite (100% target coverage) with per-test database rebuild and
  fixtures, PHPStan level max, ECS and Rector wired as composer scripts.
  Run via the dev container documented in `AGENTS.md`.
* **CI Workflow (GitHub Actions)**
  ECS, Rector, PHPStan (level max) and the PHPUnit suite run on every push
  and pull request against a real PostgreSQL 16 service container.
  Keeps every change honest before it lands on the default branch.
* **Dev Image**
  `jbsnewmedia/avalynxoffice-dev` ships the dev dependencies and the
  composer-bin tooling; the whole `composer test` gate runs against a
  mounted working copy or directly inside the image.
  No local PHP installation required.

**Compatibility**: Initial release candidate — expect API and schema
changes until the 1.0.0 stable release.
